## Cómo agregar o activar un portal
Abre el archivo `js/portals.js`, ubica el bloque correspondiente al portal y actualiza:
- `status`: cambiar de `'upcoming'` a `'active'`.
- `statusLabel`: cambiar a `'Activo · En vivo'`.
- `url`: pegar la URL pública del portal.
